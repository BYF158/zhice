# 部署与运行指南（智测心理测试系统 / zhice）

> 适用版本：zhice 3.9.0（RuoYi-Vue 3.9.0 + Spring Boot 2.5.15 + Vue 2 / vue-cli 4.4.6）
> 适用对象：在一台自有服务器（或本机）上从零把系统跑起来
> 编写日期：2026-10-24

---

## 0. 部署架构

```
                    ┌──────────────────────────────┐
  浏览器  ────────► │ nginx :80                     │
                    │  ├─ /            → dist 静态   │
                    │  └─ /prod-api/   → 反向代理 ──┼──► Spring Boot :8080 (etsong-admin.jar)
                    └──────────────────────────────┘         │
                                                             ├──► MySQL 8.0（zhice 库）
                                                             └──► Redis 6379（token / 验证码 / 缓存）
```

前后端分离：前端 `VUE_APP_BASE_API = /prod-api`，由 nginx 反代到后端；后端无 session，认证靠 JWT（`token.secret`）。

---

## 1. 环境要求

| 组件 | 版本 | 说明 |
|-----|------|------|
| JDK | **1.8**（推荐 8u302+） | `pom.xml` 中 `java.version=1.8`；JDK 11 可跑，17+ 未验证 |
| Maven | 3.6+ | 打包用；离线环境需预热依赖 |
| MySQL | **8.0.x** | 驱动为 `mysql-connector-j` 8.x，脚本按 8.0 语法（`utf8mb4`） |
| Redis | 5.0+ | 默认 `localhost:6379`，无密码 |
| Node.js | **14.x / 16.x**（推荐 16 LTS） | vue-cli 4 + webpack 4，Node 17+ 易触发 `ERR_OSSL_EVP_UNSUPPORTED` |
| npm | 6.x+ | 建议配镜像：`npm config set registry https://registry.npmmirror.com` |
| nginx | 1.18+ | 静态站点 + 反向代理 |

端口占用：80（nginx）、8080（后端）、3306（MySQL）、6379（Redis）。

## 2. 第一步：数据库

### 2.1 建库

```sql
CREATE DATABASE `zhice` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

```bash
mysql -uroot -p -e "CREATE DATABASE \`zhice\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
```

### 2.2 导入脚本（顺序不能反）

| 顺序 | 文件 | 内容 | 说明 |
|-----|------|------|------|
| 1 | `sql/ry-vue20250725.sql` | 30 张表 | **基础库，用这个**（最新，含 `personality_*` 5 张业务表 + 若依系统表，菜单最大 ID 3013） |
| 2 | `sql/quartz.sql` | `qrtz_*` 11 张表 | 基础 dump 里**不含** quartz 表，用定时任务必须补 |
| 3 | `sql/mbti_20251021.sql` | 4 表 + 60 题 + 16 型 + 菜单 4000~4007 | MBTI 模块；脚本自带 `DROP TABLE IF EXISTS`，可重复执行 |

```bash
mysql -uroot -p zhice < sql/ry-vue20250725.sql
mysql -uroot -p zhice < sql/quartz.sql
mysql -uroot -p zhice < sql/mbti_20251021.sql
```

> 不要用 `sql/ry_20250522.sql`（若依官方 19 表原始版，缺 `personality_*`）和 `sql/ry-vue20250704.sql`（旧版 dump，同样缺 `personality_*`）。

### 2.3 导入结果自检

```sql
-- 表数量：应为 45（30 基础 + 11 quartz + 4 mbti）
SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='zhice';

-- MBTI 题库与类型
SELECT COUNT(*) FROM mbti_questions;                 -- 期望 60
SELECT dimension, COUNT(*) FROM mbti_questions GROUP BY dimension;  -- EI/SN/TF/JP 各 15
SELECT COUNT(*) FROM mbti_types;                     -- 期望 16

-- MBTI 菜单
SELECT menu_id, menu_name, perms FROM sys_menu WHERE menu_id BETWEEN 4000 AND 4007;  -- 期望 8 行

-- 默认管理员
SELECT user_name, status FROM sys_user WHERE user_name='admin';
```

默认账号：`admin / admin123`（首次登录后立即改密）。

### 2.4 建议的账号隔离

生产环境不要用 root 连库：

```sql
CREATE USER 'zhice'@'localhost' IDENTIFIED BY '强密码';
GRANT ALL PRIVILEGES ON `zhice`.* TO 'zhice'@'localhost';
FLUSH PRIVILEGES;
```

## 4. 第三步：后端配置（**4 处必须改**）

### 4.1 数据库连接 —— `zhice-admin/src/main/resources/application-druid.yml`

当前仓库里指向的是一台远程开发库（`120.27.244.95:3306/ry-vue`，账号 `admin/123456`），**必须换成自己的库**：

```yaml
master:
    url: jdbc:mysql://127.0.0.1:3306/zhice?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai
    username: zhice
    password: 你的密码
```

要点：
- `useSSL=false` + `allowPublicKeyRetrieval=true`：MySQL 8 默认 `caching_sha2_password`，否则报 `Public Key Retrieval is not allowed`
- `serverTimezone=Asia/Shanghai`：避免时间差 8 小时
- 从库 `slave.enabled` 保持 `false`

### 4.2 文件上传根目录 —— `application.yml`

```yaml
ruoyi:
  # Windows 示例：D:/ruoyi/uploadPath；Linux 建议 /data/zhice/uploadPath
  profile: /data/zhice/uploadPath
```

目录必须**预先存在且有写权限**（`mkdir -p /data/zhice/uploadPath && chown -R 运行用户 /data/zhice/uploadPath`），否则上传/头像功能报错。

### 4.3 端口、Redis、令牌密钥

```yaml
server:
  port: 8080          # 改了端口，nginx 反代也要跟着改

spring:
  redis:
    host: localhost
    port: 6379
    password:          # 无密码留空
    database: 0

token:
  secret: 请替换为≥32位的随机串    # 默认 abcdefghijklmnopqrstuvwxyz，生产必须改
  expireTime: 30                  # 分钟，超时无操作自动登出
```

### 4.4 生产建议

```yaml
spring:
  devtools:
    restart:
      enabled: false     # 生产关掉热部署，省内存

logging:
  level:
    com.etsong: info     # 默认 debug，生产建议 info
```

## 5. 第四步：后端打包

```bash
cd zhice
mvn -v                                    # 确认 Maven 用的是 JDK 1.8
mvn clean package -DskipTests -pl zhice-admin -am
```

产物：`zhice-admin/target/etsong-admin.jar`（`finalName` = `${project.artifactId}` = `etsong-admin`）。

> 注意：仓库里的 `ry.sh` 里 `AppName=zhice-admin.jar`，与产物名 **不一致**。二选一：
> - 把 jar 改名：`cp zhice-admin/target/etsong-admin.jar deploy/zhice-admin.jar`
> - 或改 `ry.sh` 第 3 行：`AppName=etsong-admin.jar`

## 6. 第五步：启动后端

### 6.1 方式一：前台启动（调试）

```bash
cd /data/zhice
java -Duser.timezone=Asia/Shanghai -Xms512m -Xmx1024m -jar etsong-admin.jar
```

### 6.2 方式二：脚本后台启动（推荐）

```bash
cd /data/zhice
./ry.sh start      # start | stop | restart | status
tail -f logs/etsong-admin.jar.log
```

脚本 JVM 参数：`-Xms512m -Xmx1024m -XX:MetaspaceSize=128m -Duser.timezone=Asia/Shanghai`。若用的是 JDK 11+，把 `-XX:+PrintGCDateStamps` 删掉（JDK 14+ 已移除）。

### 6.3 启动自检

```bash
# 1) 端口在听
ss -tlnp | grep 8080

# 2) 验证码接口（不登录也能通）
curl -s http://127.0.0.1:8080/captchaImage | head -c 200

# 3) 登录拿 token（脚本验证前先临时关掉验证码）
#    MySQL 执行： UPDATE sys_config SET config_value='false' WHERE config_key='sys.account.captchaEnabled';
curl -s -X POST http://127.0.0.1:8080/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
# 返回 {"code":200,...,"token":"eyJ..."} 即后端 + 数据库 + Redis 全通
# 验证完记得把验证码开关改回 true

# 4) 带 token 取用户信息
curl -s http://127.0.0.1:8080/getInfo -H "Authorization: Bearer <token>"
```

启动失败优先看：`logs/`、控制台输出的 `Caused by`（90% 是数据库连接串 / Redis 未启动 / quartz 表缺失）。

## 7. 第六步：前端构建 + nginx

### 7.1 构建

```bash
cd zhice/zhice-ui
npm config set registry https://registry.npmmirror.com
npm install                # 首次较慢；如需可 npm ci
npm run build:prod         # 产物：dist/
```

成功标志：`DONE  Build complete. The dist directory is ready to be deployed.`
体积警告（`login-background`、`app.css`、entrypoint 1.88 MiB）属正常，可忽略。

产出目录：`zhice-ui/dist`（约 7.2 MB，含 `index.html`、`static/`、`styles/`）。

### 7.2 部署静态文件

```bash
sudo mkdir -p /data/www/zhice
sudo rsync -a --delete zhice-ui/dist/ /data/www/zhice/
```

### 7.3 nginx 站点配置

`/etc/nginx/conf.d/zhice.conf`：

```nginx
server {
    listen       80;
    server_name  zhice.example.com;   # 或服务器 IP
    charset      utf-8;

    # 上传大小上限（后端 10MB/文件、20MB/请求，这里留余量）
    client_max_body_size 50m;

    gzip on;
    gzip_min_length 1k;
    gzip_comp_level 5;
    gzip_types text/css application/javascript application/json image/svg+xml;
    gzip_vary on;

    root  /data/www/zhice;
    index index.html;

    # 前端 history 路由（/mbti/test 这类地址刷新不能 404）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源长缓存（文件名带 hash）
    location /static/ {
        expires 30d;
        add_header Cache-Control "public, max-age=2592000";
    }

    # 后端反向代理：前端 VUE_APP_BASE_API = /prod-api
    location /prod-api/ {
        proxy_pass              http://127.0.0.1:8080/;
        proxy_set_header        Host              $host;
        proxy_set_header        X-Real-IP         $remote_addr;
        proxy_set_header        X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header        X-Forwarded-Proto $scheme;
        proxy_read_timeout      300s;
        proxy_send_timeout      300s;
        proxy_connect_timeout   10s;
        # 导出 Excel 等大响应不要缓冲
        proxy_buffering         off;
    }
}
```

```bash
sudo nginx -t && sudo nginx -s reload
```

> `/prod-api/` 结尾的斜杠和 `proxy_pass` 结尾的斜杠都要保留，否则会拼成 `/prod-api/login` 打到后端导致 404。

### 7.4 HTTPS（可选）

```bash
sudo certbot --nginx -d zhice.example.com
```

## 9. 常见问题

| 现象 | 原因 | 处理 |
|-----|------|------|
| 启动报 `Public Key Retrieval is not allowed` | MySQL 8 认证插件 | JDBC 串加 `allowPublicKeyRetrieval=true&useSSL=false` |
| 启动报 `Unable to connect to Redis` | Redis 未启动 / 端口错 | `redis-cli ping`，改 `spring.redis.*` |
| 启动报 `Table 'qrtz_locks' doesn't exist` | 没导 `quartz.sql` | 补导 quartz 表，或停用定时任务模块 |
| 页面能开但接口 404 | `proxy_pass` 少尾斜杠 / 后端未启动 | 按 7.3 检查；`curl 127.0.0.1:8080/captchaImage` |
| 登录提示验证码错误 | Redis 没写进去或 token 过期 | 清浏览器缓存、`redis-cli keys '*'` 看是否有 captcha 键 |
| 刷新子页面 404 | 缺 `try_files ... /index.html` | 按 7.3 补 |
| 菜单里看不到 MBTI | 未导 `mbti_20251021.sql` 或角色未分配菜单 | 查 `sys_menu` 4000~4007；给角色勾选并重新登录 |
| 上传/头像报错 | `ruoyi.profile` 目录不存在 | `mkdir -p` + 授权 |
| 时间差 8 小时 | JDBC 未设时区 / JVM 时区不对 | 串加 `serverTimezone=Asia/Shanghai`，启动加 `-Duser.timezone=Asia/Shanghai` |
| 前端构建报 `ERR_OSSL_EVP_UNSUPPORTED` | Node 17+ | 换 Node 16 LTS，或 `NODE_OPTIONS=--openssl-legacy-provider` |
| `ry.sh start` 说找不到应用 | jar 名不匹配 | 见第 5 步说明，改名或改脚本 |

## 10. 停止与回滚

```bash
# 后端
./ry.sh stop            # 或 kill -15 <pid>（优雅停机）
./ry.sh status

# nginx
sudo nginx -s stop      # 或 systemctl stop nginx

# 回滚：前端保留上一版 dist 备份
sudo rsync -a /data/www/zhice/ /data/www/zhice.bak.$(date +%F)/
# 代码回滚
git log --oneline -5 && git checkout <上一次commit>
mvn clean package -DskipTests -pl zhice-admin -am
```
